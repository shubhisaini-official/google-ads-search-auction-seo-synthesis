## ⚙️ Core Knowledge Modules

### 1. Paid Search Auction Calculations
In Google Search Ads auctions, position is determined by **Ad Rank**, not monetary bid alone:

$$\text{Ad Rank} = \text{Maximum Bid (CPC)} \times \text{Quality Score}$$

* **2-Way Auction Breakdown:**
  * Advertiser X: $\text{Bid } \$50 \times \text{Quality Score } 6 = \mathbf{300 \text{ Ad Rank}}$
  * Advertiser Y: $\text{Bid } \$90 \times \text{Quality Score } 3 = \mathbf{270 \text{ Ad Rank}}$
  * *Verdict:* Advertiser X wins top position while paying less per click because higher Quality Score outperforms pure spend.

### 2. User Intent & Landing Page Routing
* **Informational ("What is a SIP?"):** Must route to educational explainer pages. Direct sales CTAs cause immediate bounces.
* **Commercial Comparison ("FD vs RD"):** Requires side-by-side comparative feature/rate tables.
* **Constraint Searches ("Running shoes under ₹5,000"):** Requires exact filtered inventory matching budget constraints.
